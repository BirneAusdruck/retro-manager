# CLAUDE.md

Arbeitsregeln für dieses Projekt. Jede Regel steht genau einmal in `docs/`; die folgenden Dateien werden hier eingebunden und gelten verbindlich:

- Projekt, Übersicht aller Docs und Pflege der Docs: @docs/README.md
- Architektur und Code-Regeln (MVC, Oberfläche, Nebenläufigkeit, Dateien, Geheimnisse): @docs/architecture.md
- Befehle, Tests, Entwicklungsumgebung: @docs/development.md

## Arbeitsweise

- Vor Arbeit an einem Reiter dessen `docs/features/<name>.md` lesen, vor Arbeit an einer Schnittstelle die passende `docs/specs/<name>.md`.
- Nach einer Änderung die betroffenen Docs nachziehen (wohin was gehört: `docs/README.md`).
- Nicht ohne Auftrag committen.
